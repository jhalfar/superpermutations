# The certificates of Theorem C that Lean checks at the default level of build.sh: the small ones.
# certificates-large.txt has the others, which "build.sh full" adds.
#
# A line is:  GENERATOR  k  cn  bn  q  [options of the generator]
#
# It stands for the statement ModelStatement k cn bn q (LowerBounds/SModelDef.lean): on k symbols every window
# satisfies the inequality with c = cn/q and b = bn/q.  Its files are LowerBounds/SGen/C<k>_<cn>_<bn>_<q>*.lean
# in the build directory.  GENERATOR is tools/s_plan.py or tools/s_plan2.py; the options (--leaf, --band,
# --per-file, --plain) only decide how the search is cut into lemmas and files and how its states are written,
# not what is proven.  The bound that Theorem C draws from each certificate is in the comments of the generated
# LowerBounds/SCertWSmall.lean and SCertW.lean, and README.md lists the best one for each k.  To add a
# certificate, add a line and run build.sh with CHECK_GENERATED=0.
